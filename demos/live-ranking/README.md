# 实时排名交互 Demo

独立、纯前端预览，延续正式网站的深绿与金色视觉。优先适配手机竖屏，桌面展示并列的排名与动态。所有用户、分数和得分事件均为模拟数据；不会请求项目 API、写数据库或更改正式页面。

## 启动

在仓库根目录执行（需要 Node.js）：

```powershell
node demos/live-ranking/serve.mjs
```

浏览器打开 http://localhost:4174/ 。服务仅监听本机。桌面顶部的「手机视图」可以预览窄屏布局；实际小屏宽度自动适配。

## 体验

- 下一次得分：逐次演示 7 个事件，包括反超、被反超和最终登顶。
- 自动演示 / 暂停：每 4 秒推进一次，最后自动结束；页面隐藏时暂停。
- 全部 / 我的附近：附近保留自己的前后各两名及全榜名次。
- 定位我的卡片：滚动至自己的卡片并将焦点移入。
- 点击排名卡片：展开已开赛球员的位置、姓名、比赛状态和模拟梦幻分；未开赛球员隐藏，已完赛球员保留。
- 重置：恢复初始分数和事件进度；刷新也会恢复初始状态。

同分使用并列名次。分数以整数十分之一存储，避免小数累计误差。系统开启减少动态效果时，取消数字和卡片移动动画。

## 检查

```powershell
node demos/live-ranking/check.mjs
node --check demos/live-ranking/app.mjs
```

这是供交互评审的独立 Demo，尚未接入正式实时比分，也未部署。正式计分规则、数据更新机制和用户权限需要在后续正式版本中另外落实。
